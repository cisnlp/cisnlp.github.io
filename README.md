# Schütze Lab Website

This is the website of our academic research group at LMU Munich.

This website is powered by Jekyll and some Bootstrap, Bootwatch. We tried to make it simple yet adaptable, so that it is easy for you to use it as a template. Plese feel free to copy and modify for your own purposes.  You don't have to link to us or mention us (but of course we appreciate it).

Go to *_pages.aboutwebsite.md* for Jekyll-specific instructions.

## Structure

- `_data` contains `.yml` files that are integrated into the HTML pages. Here you can update events, news, and staff members.
- `_includes` contains display settings for basic website components (navbar, footer, header, etc).
- `_pages` contains the `.md` files for each page. Here you can update the actual content of the website.
- `css` contains a `.css` file that will override the default styles. Only add to this if you want to add something specific to the page you're working on. To alter default styles, refer to the `_sass/bootstrap` files.
- `scripts` contains the scripts used to fetch the publications from the Publications page; and to generate thumbnails for the Project pages.

## What to update and when
### News
- New staff member
- On-site talk
- Paper acceptance notifications
- A staff member is hosting a workshop
- A staff member is giving a talk
- etc...

### Events
These are seminar (or other) talks, by visiting researchers. I (@leonorv) use Hinrich's seminar emails as a source for the content.
